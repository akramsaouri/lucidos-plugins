# lucidos-plugins

Plugins for [Lucidos](https://lucidos.dev/).

Register this repo as a marketplace in Lucidos (**Settings → Marketplaces**) to
browse and install these from the Plugins panel:

```
https://github.com/akramsaouri/lucidos-plugins
```

Or install one directly by pasting its tree URL.

## Plugins

| Plugin | What it does |
|---|---|
| [email-triage](./email-triage) | Per-account email triage that only interrupts you when mail genuinely needs you. Your rules run first (first-match-wins); the rest falls through to AI triage. Ships a control-panel app, the engine knowhow, and the per-account intent. |
